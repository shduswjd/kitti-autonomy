# LiDAR Perception

`lidar.py`에서 KITTI LiDAR 전처리와 장애물 군집화를 구현했다. 데이터는 공통 `KittiLoader`로 읽고 Open3D로 처리한다.

프로젝트 루트에서 실행:

```bash
source .venv/bin/activate
python -m perception.lidar
```

처리 순서:

1. 관심 영역 추출: 전방 0~50m, 좌우 ±20m, 높이 -2.5~2m
2. Voxel downsampling: 0.15m
3. RANSAC 지면 제거: 평면 거리 기준 0.2m
4. DBSCAN 군집화: eps 0.6m, 최소 점 10개
5. 군집별 축 정렬 bounding box 추출

현재 실행하면 지면으로 판단한 점과 지면 제거 후 남은 점을 순서대로 보여준다. 첫 창을 닫으면 두 번째 창이 열린다. 박스 시각화는 실행 부분의 주석으로 남겨뒀다.

## 확인한 내용과 다음 작업

첫 프레임에서 지면이 대체로 분리되는 것을 시각적으로 확인했고, 추정 평면 기울기는 약 0.3°였다. 현재 RANSAC은 가장 큰 평면을 선택하며 법선 방향으로 지면 후보를 제한하지는 않는다.

길게 이어진 구조물이 하나의 군집으로 묶여 큰 박스가 생기는 경우가 있었다. 다음에는 지면 제거 후 점들을 BEV 점유 격자에 표시하고 local planning 연결을 준비한다. 점이 없는 칸을 바로 주행 가능한 공간으로 간주하지는 않는다.
